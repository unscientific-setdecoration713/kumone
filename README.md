## 🛠️ Troubleshooting

### App Won't Open

If kumone doesn't open:

1. **Check your macOS version** - Ensure you're running macOS 12.0 or later
2. **Right-click the app** and select "Open" to bypass security checks
3. **Reinstall** the application if issues persist

### Music Won't Play

If you experience playback issues:

- **Check your internet connection**
- **Sign out and sign back in** to refresh your session
- **Clear the app cache** in Settings → Advanced

### Sync Issues

For syncing problems:

- **Ensure you're signed in** to the same account on all devices
- **Check your network connection**
- **Restart the application** after any network changes

## ❓ Frequently Asked Questions

### Do I need a NetEase Cloud Music account?

Yes, you need an active NetEase Cloud Music account to use kumone. The app requires authentication to access music content.

### Is kumone free?

Kumone itself is free to use. You may need a NetEase Cloud Music membership for some premium features like lossless audio.

### Can I use kumone on Windows?

No, kumone is specifically built for macOS using Apple's SwiftUI framework and is not available on other operating systems.
